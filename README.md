# A1_5-Lab-Termodinamica

Repository condivisa per il gruppo di laboratorio di termodinamica.

## Struttura esercitazioni
Sono state predisposte le cartelle per tutte le prove:
- `PP1/`
- `PP2/`
- `PP3/`
- `PP4/`
- `PP5/`
- `PP6/`

Per ogni prova, ciascun membro può caricare i propri andamenti nella cartella corrispondente (es. `PP3/nome-cognome/`).

## Collaborazione del gruppo
Per fare in modo che tutti i 4 partecipanti possano fare commit direttamente:
1. Aprire **Settings > Collaborators and teams** della repository
2. Invitare gli altri 3 membri del gruppo
3. Assegnare permesso **Write** (o superiore)

In questo modo tutti potranno aggiornare la repository man mano, ogni 2 settimane, per le relazioni da PP1 a PP6.
